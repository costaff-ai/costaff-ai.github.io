open-spreadsheet

Spreadsheets for agents and people

An Excel-like spreadsheet where each workbook is one JSON file of what people typed, so a person edits it in a real grid and an agent edits the file. For teams who want their numbers in git.

npx open-spreadsheet init my-sheets
View on GitHub

What it does.

Its own formula engine

337 functions following Excel's rules, with no spreadsheet library underneath.

A grid like Excel

Formula bar, number formats, merges, frozen panes, filters, notes and sheet tabs.

One JSON file per workbook

Cells store what was typed, including formulas, so git shows every change.

CSV and Excel import, export

Import .csv, .tsv or .xlsx and download .xlsx or CSV, without uploading anything.

Protected ranges

Locked cells refuse typing, pasting and MCP writes, so an agent cannot change them.

MCP server with 29 tools

Every write recalculates and is refused if the file changed since it was read.

Get started.

Create a workspace

One command makes a new folder for your work.

npx open-spreadsheet init my-sheets

Start it

The live preview opens in your browser.

cd my-sheets && pnpm install && pnpm dev

Ask your agent

Say what you need. The agent writes the files and you watch them change.
