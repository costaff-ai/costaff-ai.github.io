open-map

Maps and story maps for agents

A map framework for coding agents: your agent writes each map as a React component, and open-map handles projections, layers, guided story chapters and export. For people telling stories with places and routes.

git clone https://github.com/simonliu-ai-product/open-map.git && cd open-map && pnpm install
View on GitHub

What it does.

Map layers as components

Choropleth, route, arc, point and heatmap layers, plus markers and callouts, in plain TSX.

Three projections

Web Mercator, equirectangular and an orthographic globe, with scale bar, north arrow and inset map.

GeoJSON and CSV imports

Spatial files import as modules, and open-map import builds a new map from one.

Story mode

StoryChapter stops turn a map into a guided tour with camera fly-to and keyboard navigation.

Inspect and comment

Click a feature to see its source line, leave a note, or save the current camera to source.

MCP server

open-map dev --mcp exposes tools to list, read, write, check and import maps.

Get started.

Create a workspace

One command makes a new folder for your work.

git clone https://github.com/simonliu-ai-product/open-map.git && cd open-map && pnpm install

Start it

The live preview opens in your browser.

pnpm dev:demo

Ask your agent

Say what you need. The agent writes the files and you watch them change.
