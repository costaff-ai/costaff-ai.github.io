open-design-frame

用元件寫設計稿

每張 frame 都是固定尺寸的畫板，例如桌機畫面、手機畫面或海報，由 Agent 用 TSX 寫成；畫布以實際尺寸呈現，檢視器直接改寫原始檔。適合想讓設計稿與程式碼放在同一處的設計師與開發者。

npx @open-design-frame/core init my-frames
在 GitHub 查看

能做什麼

以實際尺寸呈現

每張 frame 帶著自己的尺寸，畫布縮放的是外框，不是內容。

改畫布就是改原始碼

點任一元素、在檢視器調整，按 Save 就寫回 TSX。

像網站一樣播放

在模擬的瀏覽器或手機裡點過一張張 frame，依 frame 自己宣告的連結走。

主題附帶 DESIGN.md

token 變成 CSS 變數，旁邊的 DESIGN.md 寫下 token 裝不下的規則給 Agent 看。

一個 zip 匯出

可獨立開啟的 HTML、1x／2x／3x 的 PNG 與 SVG，每張 frame 都以自己的尺寸輸出。

MCP server

open-design-frame dev --mcp 提供 32 個工具，過期的寫入會被拒絕。

開始使用

建立工作區

一個指令建立新的資料夾。

npx @open-design-frame/core init my-frames

啟動

在瀏覽器打開即時預覽。

cd my-frames && pnpm install && pnpm dev

交給 Agent

說出你要什麼，Agent 寫檔案，你看著畫面跟著變。

設計一個手機版引導頁和一個桌機版價格頁

在 CoStaff Workspace 裡打開

Agent 的每一次修改，都即時出現在對話旁邊。支援 Antigravity App 與 VS Code。
