開源

為 Agent 打造的生產力工具

文件、簡報、試算表、儀表板，Agent 寫得出來、人看得懂，全部是資料夾裡的檔案。每一個都是開源框架，附 skills 與 MCP server。

是檔案，不是 App

所有內容都是資料夾裡的文字。不論是你還是 Agent 改的，git 都看得到。

即時預覽

開發伺服器一邊寫一邊呈現，用實際的尺寸。

Agent 懂的工具

skills 與 MCP server 告訴 Agent 怎麼做、怎麼檢查、怎麼修正。

自製工具

可在 Workspace 開啟

open-doc

用 React 寫報告，輸出真正的 A4 頁面，含大綱、頁碼與 PDF。

open-dashboard

描述你要的儀表板，Agent 直接連你的資料庫做出即時看板。

open-spreadsheet

類 Excel 的試算表：自製公式引擎、格子編輯器、xlsx 與 MCP server。

open-design-frame

用元件寫設計稿，依實際尺寸繪製，並提供 MCP 介面。

其他工具

open-form

表單、問卷、報名：對話式填答、回覆儲存與分析。

open-map

互動地圖與 story map，投影、圖層與匯出都處理好。

open-recording

在瀏覽器錄影、在本機轉逐字稿，兩者都交給 Agent 操作。

外部／第三方工具

open-slide 作者 1weiho

為 Agent 打造的簡報框架：用 React 元件做簡報。

可在 Workspace 開啟

open-sheet 作者 lianghsun

用 React 寫試算表模型，匯出會自動重算的 .xlsx。
