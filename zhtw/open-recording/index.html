open-recording

給 Agent 用的錄音工作室

在瀏覽器錄音，用 whisper.cpp 在本機轉錄，讓 Agent 透過 MCP 兩件都能自己來。適合想把會議或演講轉成逐字稿、又不想把音檔送出去的人。

npx -p @open-recording/core open-recording init my-recordings
在 GitHub 查看

能做什麼

在瀏覽器錄音

工作室分頁負責麥克風，Agent 可以自己開始與停止錄音。

本機轉錄

whisper.cpp 在你的電腦上轉錄，音訊不離開這台機器。

給 Agent 的 MCP 工具

開始、停止、轉錄、搜尋逐字稿，並在音檔旁寫筆記。

錄瀏覽器分頁

把一個分頁的畫面與聲音錄成一段，一樣轉錄、一樣有字幕。

磁碟上的普通資料夾

每段錄音是一個資料夾，裡面是音檔、逐字稿與筆記，沒有資料庫。

字幕與 Markdown

下載音檔、SRT、VTT，或帶時間戳的 Markdown 逐字稿。

開始使用

建立工作區

一個指令建立新的資料夾。

npx -p @open-recording/core open-recording init my-recordings

啟動

在瀏覽器打開即時預覽。

cd my-recordings && pnpm add -D @open-recording/core @open-recording/mcp && pnpm exec open-recording dev --mcp

交給 Agent

說出你要什麼，Agent 寫檔案，你看著畫面跟著變。

幫我錄這場會議，結束後在旁邊寫一份摘要和待辦事項
