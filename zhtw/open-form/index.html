open-form

讓 Agent 寫的表單與問卷

為 Coding Agent 打造的表單框架：描述你要的問卷、報名表或測驗，Agent 寫 TSX，open-form 處理版面、條件邏輯、驗證與回覆儲存。適合不想依賴線上表單服務收集回覆的人。

git clone https://github.com/simonliu-ai-product/open-form.git && cd open-form && pnpm install
在 GitHub 查看

能做什麼

三種呈現方式

同一份 TSX 可以是單頁表單、分步精靈，或一次一題的對話卡片。

15 種題型

文字、數字、日期、選擇、排序、評分、量表、矩陣、檔案上傳與簽名。

條件跳題與測驗計分

用 when 依前面的回答顯示題目，或以配分與解析把表單變成測驗。

回覆存在本機

提交內容寫入 SQLite 與 JSONL，回覆分頁有統計圖表，可匯出 CSV 或 JSON。

附簽章的 Webhook

每筆回覆可用 HTTP POST 轉發，並可加上 HMAC-SHA256 簽章。

編輯模式改的是原始碼

在瀏覽器改標題、選項或必填，直接寫回 TSX。

開始使用

建立工作區

一個指令建立新的資料夾。

git clone https://github.com/simonliu-ai-product/open-form.git && cd open-form && pnpm install

啟動

在瀏覽器打開即時預覽。

pnpm dev

交給 Agent

說出你要什麼，Agent 寫檔案，你看著畫面跟著變。
