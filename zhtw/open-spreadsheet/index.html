open-spreadsheet

人和 Agent 共用的試算表

用起來像 Excel 的試算表，每份活頁簿都是一個 JSON 檔，存的是人輸入的內容：人在格子裡編輯，Agent 直接改檔案。適合想把數字放進 git 的團隊。

npx open-spreadsheet init my-sheets
在 GitHub 查看

能做什麼

自己寫的公式引擎

337 個函數，照 Excel 的規則計算，底層沒有任何試算表套件。

像 Excel 的格子介面

公式列、數值格式、合併儲存格、凍結窗格、篩選、註解與工作表分頁。

一份活頁簿一個 JSON 檔

儲存格存的是輸入的內容（包含公式），git 看得到每一處修改。

CSV 與 Excel 匯入匯出

匯入 .csv、.tsv 或 .xlsx，下載 .xlsx 或 CSV，什麼都不會上傳。

保護範圍

鎖定的儲存格拒絕輸入、貼上與 MCP 寫入，Agent 改不了人鎖住的內容。

29 個工具的 MCP server

每次寫入都會重算，檔案在讀取後被改過就拒絕寫入。

開始使用

建立工作區

一個指令建立新的資料夾。

npx open-spreadsheet init my-sheets

啟動

在瀏覽器打開即時預覽。

cd my-sheets && pnpm install && pnpm dev

交給 Agent

說出你要什麼，Agent 寫檔案，你看著畫面跟著變。

做一份 2026 年預算表，要有每月合計和累計餘額

在 CoStaff Workspace 裡打開

Agent 的每一次修改，都即時出現在對話旁邊。支援 Antigravity App 與 VS Code。
