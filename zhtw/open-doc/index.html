open-doc

讓 Agent 寫的文件

為 Coding Agent 打造的文件框架：你描述要的報告，Agent 寫 React，open-doc 處理頁面尺寸、目錄、頁碼、列印版面與匯出。適合需要一份經得起印表機考驗的 PDF 的人。

npx @open-document/cli init my-docs
在 GitHub 查看

能做什麼

真實的頁面尺寸

頁面以真正的 A4、JIS B4 或 A3 尺寸呈現，PDF 與螢幕上看到的一致。

懂規矩的自動分頁

flow() 在真實 DOM 中量測內容：標題不會落在頁尾，表格整張移動。

版面體檢

open-doc check 會列出被裁切的內容、落單的標題與載入失敗的圖片，並附上原始碼行號。

直接在頁面上編輯

Inspect 模式把改寫的文字直接寫回原始碼，或留一則註記給 Agent。

表格來自資料檔

匯入 .csv 或 .tsv 檔就成為有編號與標題的表格，檔案一改表格就跟著改。

Skills 與 MCP server

每個工作區都附上撰寫用的 Skills，open-doc dev --mcp 提供 26 個工具。

開始使用

建立工作區

一個指令建立新的資料夾。

npx @open-document/cli init my-docs

啟動

在瀏覽器打開即時預覽。

cd my-docs && pnpm dev

交給 Agent

說出你要什麼，Agent 寫檔案，你看著畫面跟著變。

把 notes.md 整理成一份第三季基礎架構檢討報告，要有封面和目錄

在 CoStaff Workspace 裡打開

Agent 的每一次修改，都即時出現在對話旁邊。支援 Antigravity App 與 VS Code。
