CoStaff Workspace

讓文書工作快速完成

你的 AI 同事就在眼前現場辦公。
工作區與 Agent 並排同步，每一次工具操作與修改都即時呈現。

Agent 一改，畫面就變

請 Agent 加一欄、畫一張圖、多做一頁投影片。Agent 改檔案，你正在看的畫面跟著變。不用重新整理、不用匯出，也不用「打開檔案看看」。

所有工作區，一份清單

專案裡的、你加過的、在 CoStaff Desktop 用過的，全部合成一份。最近修改的排前面，可以依類型篩選、用名稱搜尋。

像編輯器原本就有的功能

每個工作區一個分頁

可以和程式碼並排開好幾個。關掉分頁，伺服器就停止。

跟著你的主題

深色或淺色，工作區跟著編輯器，而不是跟著系統。

一鍵就緒

還沒裝套件、框架有新版，按一下就安裝或更新。

能複製貼上

複製一個範圍、貼上一整列，在工作區裡也行，連 VS Code 裡都可以。

指令面板

在 ⌘⇧P 直接打開任何工作區，不用先回清單。

你的檔案，你的資料夾

在 Finder 顯示、開啟資料夾、查看伺服器紀錄，都在同一個選單。

一切都留在你的電腦

不需要帳號，只在本機執行、只有你連得到。

兩種使用方式

Antigravity App 版

以 plugin 形式，在 Agent 對話旁邊開一個自己的分頁。

安裝說明

VS Code 版

以擴充套件形式，支援 VS Code、Cursor 與 Antigravity IDE。每個工作區開在編輯區分頁，放在檔案與 Agent 之間。

VS Code MarketplaceOpen VSX

開始使用

擴充套件已經上架 VS Code Marketplace，Cursor 與 Antigravity IDE 可以從 Open VSX 安裝。Antigravity App 版用一行 agy 指令安裝。

建立工作區

一個指令建立新的資料夾。

npx @open-document/cli init my-docs

安裝 CoStaff Workspace

在 VS Code、Cursor 或 Antigravity IDE 的擴充功能搜尋。
