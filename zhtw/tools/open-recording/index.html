The recording studio built for agents.

瀏覽器優先的錄音工具。分頁持有麥克風，伺服器持有 session。whisper.cpp 在你的機器上轉錄。沒有任何東西被上傳。

$ npx open-recording dev --mcp

工作室 — 每段錄音都是一張卡片，帶著逐字稿的開頭幾句

01 · 為什麼

麥克風在分頁裡。 狀態在伺服器上。

只有真實的分頁拿得到麥克風。所以錄音發生在瀏覽器，session、檔案與逐字稿留在 dev server。人跟 agent 因此能操作同一台錄音機。

01 · 本機

沒有東西被上傳。

whisper.cpp 跑在你的 CPU 上。音檔、逐字稿與筆記都是你資料夾裡的檔案。

02 · 共用

一台錄音機，兩個操作者。

人跟 agent 共用同一個 session。誰按停止，另一邊立刻看得到。

03 · 檔案

一段錄音就是一個資料夾。

音檔、帶時間的片段、Markdown 逐字稿、筆記。沒有資料庫，沒有索引。

$ ls recordings/<id>/
audio.webm transcript.md
meta.json notes.md
04 · 字體

要繁體就給繁體。

Whisper 一律寫簡體。設定字體後由 OpenCC 逐詞轉換，软件 變成 軟體，時間戳原封不動。

02 · 給 agent

用 MCP 按下錄音。 六個工具，一個 endpoint。

把 agent 指到 localhost:5274/mcp。開始錄音、停止時順便轉錄、讀回逐字稿、把摘要寫在音檔旁邊。

start_recording按下錄音。瀏覽器確認麥克風開了才回傳。
stop_recording停止並收尾。帶 transcribe: true 就順便跑 whisper。
read_transcript帶時間戳的 Markdown、純文字，或帶時間的片段。
search_transcripts跨所有逐字稿搜尋，附毫秒位移。
write_notes把摘要或待辦寫在音檔旁邊。
recorder_status現在有沒有在錄，以及有沒有工作室能錄。

它拒絕，而不是謊報。 start_recording 會等 MediaRecorder 確認才回傳。分頁關了、麥克風被擋，agent 拿到的是講明原因的拒絕，不是一句「好了」。

錄完的會議 — 以及 agent 寫進 notes.md 的摘要

03 · 開始使用

錄下你的下一場會議。 一個指令，麥克風授權一次。

不裝其他東西也能錄。轉錄需要 whisper.cpp 與 ffmpeg，缺哪個 doctor 會連修法一起印出來。

# 工作室在 :5274，MCP endpoint 在 /mcp
$ npx open-recording dev --mcp

# 選用——本機轉錄
$ brew install whisper-cpp ffmpeg
$ npx open-recording doctor
✓ ffmpeg    ✓ whisper    ✓ model    ✓ script
