CoStaff Tools

Agent 很會寫，
但交付需要工具。

Agent 寫得出漂亮的文字，卻做不出像樣的檔案。這兩套框架就是為了補上這一段：讓成果變成真正能交出去的東西——一份頁面尺寸正確的文件、一段自己會轉錄的錄音。兩者都是開源、都跑在你自己的機器上，也都能透過 MCP 交給 agent 操作。

01  工具

兩種媒介，同一個想法。

給 agent 一個它真正擅長的媒介——React、一個真實的瀏覽器——剩下那些這個媒介必須經得起的考驗，就交給框架：印表機、逐字稿、以及別人打開得了的檔案。

open-doc

每一頁都是一張真的 A4 紙，你的 agent 用 React 寫它。目錄、頁碼、分頁這些煩人的事，它自己會處理。

02  為什麼做這些

最後一哩，是那個檔案。

CoStaff 的 agent 早就能推理出答案，做不到的是把答案交成一個同事打開就懂、不必再問的形式。每一套工具補上其中一個缺口，而且都附自己的 MCP server——不論是我們的 agent 還是你的，都能直接操作。

跑在你自己的機器上

兩者都是自架。open-recording 不會把音訊送到任何地方——whisper.cpp 在本機轉錄，檔案就留在你自己的資料夾裡。

用 MCP 操作

每一套都在 UI 旁邊掛上 MCP endpoint，讓 agent 和人共用同一個工作區，而不是互相搶。

產出是檔案，不是資料庫

輸出就是磁碟上的一般檔案——PDF、WebM、Markdown 逐字稿。沒有任何東西被鎖在只有這個工具讀得懂的格式裡。

開源，MIT 授權

每一行都能讀、能改、能拿去用。發佈在 npm，並在 GitHub 上公開開發。
