open-map

讓 Agent 寫的地圖與敘事地圖

為 Coding Agent 打造的地圖框架：Agent 把每張地圖寫成 React 元件，open-map 處理投影、圖層、故事導覽章節與匯出。適合用地點與路線說故事的人。

git clone https://github.com/simonliu-ai-product/open-map.git && cd open-map && pnpm install
在 GitHub 查看

能做什麼

圖層就是元件

分層設色、路線、弧線、點位與熱力圖層，加上標記與標註，都用 TSX 寫。

三種投影

麥卡托、等距圓柱與正射地球儀，附比例尺、指北針與鷹眼圖。

匯入 GeoJSON 與 CSV

空間資料可直接當模組匯入，open-map import 也能從檔案產生新地圖。

故事模式

用 StoryChapter 把地圖變成導覽，鏡頭平滑飛移，可用鍵盤切換。

檢視與留註解

點任一圖徵看它的原始碼行號、留註解，或把目前視角存回原始碼。

MCP server

open-map dev --mcp 提供列出、讀取、寫入、檢查與匯入地圖的工具。

開始使用

建立工作區

一個指令建立新的資料夾。

git clone https://github.com/simonliu-ai-product/open-map.git && cd open-map && pnpm install

啟動

在瀏覽器打開即時預覽。

pnpm dev:demo

交給 Agent

說出你要什麼，Agent 寫檔案，你看著畫面跟著變。

畫一張台灣高壓電網地圖，每個區域一個故事章節
