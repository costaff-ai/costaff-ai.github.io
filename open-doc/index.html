open-doc

Documents your agent writes

A document framework for coding agents: describe the report, your agent writes React, and open-doc handles page size, contents, page numbers, print layout and export. For anyone who needs a PDF that survives a printer.

npx @open-document/cli init my-docs
View on GitHub

What it does.

Real page sizes

Pages render at true A4, JIS B4 or A3 size, so the PDF matches what you see on screen.

Pagination that knows the rules

flow() measures content in the real DOM: headings never end a page and tables move whole.

Layout checks

open-doc check reports clipped content, stranded headings and missing images, with the source line.

Edit on the page

Inspect mode rewrites text straight into the source, or leaves a note for your agent.

Tables from data files

Import a .csv or .tsv file and it becomes a captioned, numbered table that updates with the file.

Skills and an MCP server

Every workspace ships with authoring skills, and open-doc dev --mcp exposes 26 tools.

Get started.

Create a workspace

One command makes a new folder for your work.

npx @open-document/cli init my-docs

Start it

The live preview opens in your browser.

cd my-docs && pnpm dev

Ask your agent

Say what you need. The agent writes the files and you watch them change.
