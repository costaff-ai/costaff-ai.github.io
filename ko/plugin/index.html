CoStaff Workspace

문서 작업을 빠르게 끝내세요.

AI 동료가 바로 눈앞에서 일합니다.
워크스페이스가 에이전트 옆에 나란히 열리고, 모든 도구 호출과 수정 사항이 실시간으로 나타납니다.

에이전트가 일하는 대로 실시간으로

열 추가, 차트, 슬라이드 한 장 더. 에이전트가 파일을 고치면 지금 보고 있는 화면도 함께 바뀝니다. 새로고침도, 내보내기도, “파일 열어서 확인”도 필요 없습니다.

모든 워크스페이스를 한 목록에

프로젝트 안의 워크스페이스, 직접 추가한 워크스페이스, CoStaff Desktop에서 쓰던 워크스페이스까지 한곳에 모았습니다. 최근 변경 순으로 정렬하고, 종류별로 거르고, 이름으로 찾을 수 있습니다.

에디터에 원래 있던 기능처럼

워크스페이스마다 탭 하나

코드 옆에 여러 개를 나란히 열 수 있습니다. 탭을 닫으면 서버도 멈춥니다.

내 테마 그대로

라이트든 다크든, 워크스페이스는 시스템이 아니라 에디터 설정을 따릅니다.

클릭 한 번으로 준비

패키지가 없거나 프레임워크 새 버전이 나왔다면 버튼 하나로 설치하거나 업데이트합니다.

복사와 붙여넣기

범위를 복사하고 행을 붙여넣으세요. VS Code 안에서도 워크스페이스에서 그대로 됩니다.

명령 팔레트

목록으로 돌아가지 않고 ⌘⇧P에서 바로 워크스페이스를 엽니다.

내 파일, 내 폴더

Finder에서 보기, 폴더 열기, 서버 로그 확인을 메뉴 하나에서 할 수 있습니다.

모든 것이 내 컴퓨터에 남습니다.

계정이 필요 없습니다. 내 컴퓨터에서만 실행되고, 나만 접속할 수 있습니다.

두 가지 사용 방법

Antigravity App용

플러그인으로 설치합니다. 워크스페이스가 별도 탭으로 열려 에이전트 대화 바로 옆에 놓입니다.

설치 가이드

agy 명령어 하나로 설치합니다.

VS Code용

VS Code, Cursor, Antigravity IDE용 확장 프로그램입니다. 워크스페이스마다 에디터 탭으로 열립니다.

VS Code MarketplaceOpen VSX

Open VSX는 Cursor와 Antigravity IDE의 확장 프로그램 마켓플레이스입니다.

시작하기

확장 프로그램은 VS Code Marketplace에 있으며, Cursor와 Antigravity IDE에서는 Open VSX로 설치할 수 있습니다. Antigravity App에서는 agy 명령어 하나로 플러그인을 설치합니다.

워크스페이스 만들기

명령어 하나로 작업용 새 폴더를 만듭니다.

npx @open-document/cli init my-docs
