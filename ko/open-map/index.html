open-map

에이전트를 위한 지도와 스토리 맵

코딩 에이전트를 위한 지도 프레임워크입니다. 에이전트가 지도를 React 컴포넌트로 작성하면, open-map이 투영, 레이어, 안내형 스토리 챕터, 내보내기를 처리합니다. 장소와 경로로 이야기를 전하는 분께 맞습니다.

git clone https://github.com/simonliu-ai-product/open-map.git && cd open-map && pnpm install
GitHub에서 보기

할 수 있는 일

컴포넌트로 쓰는 지도 레이어

단계구분도, 경로, 호, 포인트, 히트맵 레이어와 마커, 말풍선을 일반 TSX로 작성합니다.

세 가지 투영법

Web Mercator, 정거원통도법, 정사도법 지구본. 축척 막대, 방위 표시, 인셋 지도도 제공합니다.

GeoJSON·CSV 가져오기

공간 데이터 파일을 모듈로 가져올 수 있고, open-map import로 파일에서 새 지도를 만들 수 있습니다.

스토리 모드

StoryChapter로 지도를 안내형 투어로 바꿉니다. 카메라가 부드럽게 이동하고 키보드로 넘길 수 있습니다.

살펴보고 댓글 달기

지형지물을 클릭해 소스 줄 번호를 보고, 메모를 남기거나, 현재 카메라 위치를 소스에 저장합니다.

MCP server

open-map dev --mcp로 지도를 나열, 읽기, 쓰기, 검사, 가져오기하는 도구를 제공합니다.

시작하기

워크스페이스 만들기

명령어 하나로 작업용 새 폴더를 만듭니다.

git clone https://github.com/simonliu-ai-product/open-map.git && cd open-map && pnpm install

실행하기

브라우저에서 실시간 미리보기가 열립니다.

pnpm dev:demo

에이전트에게 요청하기

원하는 것을 말하세요. 에이전트가 파일을 작성하고, 화면이 바뀌는 모습을 바로 볼 수 있습니다.

대만 고압 송전망 지도를 그리고, 지역마다 스토리 챕터를 하나씩 만들어 줘
