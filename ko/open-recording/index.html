open-recording

에이전트를 위한 녹음 스튜디오

브라우저에서 녹음하고, whisper.cpp로 로컬에서 받아쓰고, 에이전트가 MCP로 둘 다 다룹니다. 오디오를 어디에도 보내지 않고 회의나 발표를 받아쓰고 싶은 분께 맞습니다.

npx -p @open-recording/core open-recording init my-recordings

할 수 있는 일

브라우저에서 녹음

스튜디오 탭이 마이크를 맡고, 에이전트가 녹음을 시작하고 멈출 수 있습니다.

로컬 받아쓰기

whisper.cpp가 내 컴퓨터에서 받아쓰므로 오디오가 밖으로 나가지 않습니다.

에이전트용 MCP 도구

시작, 정지, 받아쓰기, 스크립트 검색, 오디오 옆에 노트 작성까지.

브라우저 탭 녹화

탭의 화면과 소리를 하나의 녹음으로 담고, 받아쓰기와 자막도 똑같이 만듭니다.

디스크 위의 평범한 폴더

녹음마다 오디오, 스크립트, 노트가 담긴 폴더 하나이며, 데이터베이스가 없습니다.

자막과 Markdown

오디오, SRT, VTT, 또는 타임스탬프가 붙은 Markdown 스크립트로 내려받습니다.

시작하기

워크스페이스 만들기

명령어 하나로 작업용 새 폴더를 만듭니다.

npx -p @open-recording/core open-recording init my-recordings

실행하기

브라우저에서 실시간 미리보기가 열립니다.

cd my-recordings && pnpm add -D @open-recording/core @open-recording/mcp && pnpm exec open-recording dev --mcp

에이전트에게 요청하기

원하는 것을 말하세요. 에이전트가 파일을 작성하고, 화면이 바뀌는 모습을 바로 볼 수 있습니다.
