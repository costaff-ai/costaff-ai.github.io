open-doc

에이전트가 쓰는 문서

코딩 에이전트를 위한 문서 프레임워크입니다. 원하는 보고서를 설명하면 에이전트가 React로 작성하고, open-doc이 페이지 크기, 목차, 페이지 번호, 인쇄 레이아웃, 내보내기를 처리합니다. 프린터로 뽑아도 깨지지 않는 PDF가 필요한 분께 맞습니다.

npx @open-document/cli init my-docs
GitHub에서 보기

할 수 있는 일

실제 페이지 크기

페이지를 실제 A4, JIS B4, A3 크기로 렌더링하므로 PDF가 화면에서 본 그대로 나옵니다.

규칙을 아는 페이지 나누기

flow()가 실제 DOM에서 콘텐츠를 측정합니다. 제목이 페이지 끝에 홀로 남지 않고, 표는 통째로 넘어갑니다.

레이아웃 검사

open-doc check가 잘린 콘텐츠, 홀로 남은 제목, 누락된 이미지를 소스 줄 번호와 함께 알려 줍니다.

페이지에서 바로 편집

Inspect 모드에서 고친 텍스트가 소스에 바로 반영되고, 에이전트에게 메모를 남길 수도 있습니다.

데이터 파일로 만드는 표

.csv나 .tsv 파일을 가져오면 번호와 캡션이 붙은 표가 되고, 파일이 바뀌면 표도 함께 바뀝니다.

Skills와 MCP server

모든 워크스페이스에 작성용 Skills가 포함되어 있고, open-doc dev --mcp로 26개 도구를 제공합니다.

시작하기

워크스페이스 만들기

명령어 하나로 작업용 새 폴더를 만듭니다.

npx @open-document/cli init my-docs

실행하기

브라우저에서 실시간 미리보기가 열립니다.

cd my-docs && pnpm dev

에이전트에게 요청하기

원하는 것을 말하세요. 에이전트가 파일을 작성하고, 화면이 바뀌는 모습을 바로 볼 수 있습니다.

notes.md를 표지와 목차가 있는 3분기 인프라 리뷰 보고서로 정리해 줘

CoStaff Workspace에서 열기

에이전트의 모든 수정 사항을 대화 옆에서 바로 확인하세요. Antigravity App과 VS Code를 지원합니다.
