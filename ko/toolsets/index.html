오픈소스

에이전트를 위한 생산성 도구

문서, 슬라이드, 스프레드시트, 대시보드. 에이전트가 작성하고 사람이 읽을 수 있는, 폴더 속 파일입니다. 모두 Skills와 MCP server를 갖춘 오픈소스 프레임워크입니다.

앱이 아니라 파일

모든 내용은 폴더 속 텍스트입니다. 내가 고치든 에이전트가 고치든 git이 모든 변경을 기록합니다.

실시간 미리보기

개발 서버가 작성되는 대로 실제 크기로 렌더링합니다.

에이전트가 아는 도구

Skills와 MCP server가 에이전트에게 만들고, 확인하고, 고치는 방법을 알려 줍니다.

자체 개발 도구

Workspace에서 열기

open-doc

React로 쓴 보고서를 목차, 페이지 번호, PDF까지 갖춘 실제 A4 페이지로 렌더링합니다.

open-dashboard

원하는 대시보드를 설명하면 에이전트가 내 데이터베이스 위에 실시간으로 만들어 줍니다.

open-spreadsheet

자체 수식 엔진, 그리드 에디터, xlsx, MCP server를 갖춘 Excel 같은 스프레드시트.

open-design-frame

컴포넌트로 작성하고 실제 크기로 그리는 디자인 프레임, MCP 엔드포인트 제공.

다른 도구

open-form

대화형 단계, 응답 저장, 분석을 갖춘 폼과 설문.

open-map

투영, 레이어, 내보내기까지 처리하는 인터랙티브 지도와 스토리 투어.

open-recording

브라우저에서 녹음하고 로컬에서 받아쓰며, 둘 다 에이전트가 조작합니다.
