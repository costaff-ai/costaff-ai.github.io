open-form

에이전트가 쓰는 폼과 설문

코딩 에이전트를 위한 폼 프레임워크입니다. 원하는 설문, 신청서, 퀴즈를 설명하면 에이전트가 TSX를 작성하고, open-form이 레이아웃, 조건 로직, 유효성 검사, 응답 저장을 처리합니다. 온라인 폼 서비스 없이 응답을 모으고 싶은 분께 맞습니다.

git clone https://github.com/simonliu-ai-product/open-form.git && cd open-form && pnpm install
GitHub에서 보기

할 수 있는 일

세 가지 표시 방식

TSX 파일 하나를 한 페이지 폼, 단계별 마법사, 한 번에 한 질문씩 보여 주는 형태로 렌더링합니다.

15가지 질문 유형

텍스트, 숫자, 날짜, 선택, 순위, 평점, 척도, 행렬, 파일 업로드, 서명.

조건 로직과 퀴즈

when으로 앞선 답변에 따라 질문을 보여 주거나, 배점과 해설로 폼을 퀴즈로 만듭니다.

응답은 로컬에 저장

제출 내용은 SQLite와 JSONL에 저장되고, 응답 탭에서 차트와 CSV·JSON 내보내기를 제공합니다.

서명된 Webhook

각 제출을 HTTP POST로 전달하며, 선택적으로 HMAC-SHA256 서명을 붙입니다.

편집 모드는 소스를 고칩니다

브라우저에서 라벨, 선택지, 필수 여부를 바꾸면 TSX에 그대로 저장됩니다.

시작하기

워크스페이스 만들기

명령어 하나로 작업용 새 폴더를 만듭니다.

git clone https://github.com/simonliu-ai-product/open-form.git && cd open-form && pnpm install

실행하기

브라우저에서 실시간 미리보기가 열립니다.

pnpm dev
