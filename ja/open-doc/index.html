open-doc

エージェントが書くドキュメント

コーディングエージェントのためのドキュメントフレームワーク。作りたいレポートを伝えるとエージェントが React を書き、ページサイズ、目次、ページ番号、印刷レイアウト、書き出しは open-doc が引き受けます。プリンターに通しても崩れない PDF が必要な方に。

npx @open-document/cli init my-docs
GitHub で見る

できること

本物のページサイズ

A4、JIS B4、A3 の実寸でページを描画するので、PDF は画面で見たとおりになります。

ルールを守る改ページ

flow() が実際の DOM で内容を計測します。見出しがページ末尾に取り残されることはなく、表はまとめて次のページへ送られます。

レイアウトチェック

open-doc check が、はみ出した内容、取り残された見出し、読み込めない画像を、ソースの行番号付きで報告します。

ページ上で編集

Inspect モードで、書き換えた文字をそのままソースに反映したり、エージェントへのメモを残したりできます。

データファイルから表を

.csv や .tsv を読み込むと、キャプションと番号付きの表になり、ファイルを更新すれば表も変わります。

Skills と MCP サーバー

どのワークスペースにも執筆用の Skills が付属し、open-doc dev --mcp で 26 個のツールを提供します。

はじめる

ワークスペースを作成

コマンドひとつで作業用のフォルダができます。

npx @open-document/cli init my-docs

起動する

ブラウザでライブプレビューが開きます。

cd my-docs && pnpm dev

エージェントに頼む

ほしいものを伝えるだけ。エージェントがファイルを書き、画面がその場で変わっていきます。

notes.md を表紙と目次付きの第3四半期インフラレビューにまとめて

CoStaff Workspace で開く

エージェントによる編集のひとつひとつを、会話のすぐ横で確認できます。Antigravity App と VS Code に対応しています。

CoStaff Workspace を見る
