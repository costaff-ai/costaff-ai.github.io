CoStaff Workspace

書類仕事を、すばやく片づける

AI の同僚が、目の前で仕事をします。
ワークスペースはエージェントのすぐ横にあり、ツールの呼び出しも編集も、その場で表示されます。

エージェントの作業がそのまま見える

列を追加して、グラフを描いて、スライドをもう 1 枚。エージェントがファイルを編集すると、見ている画面も一緒に変わります。再読み込みも書き出しも、「ファイルを開いて確認」も要りません。

すべてのワークスペースを、ひとつのリストに

プロジェクト内のもの、自分で追加したもの、CoStaff Desktop で使ったもの。最近更新した順に並び、種類で絞り込み、名前で検索できます。

エディタにすっかりなじむ

ワークスペースごとにタブ

コードと並べて複数開けます。タブを閉じるとサーバーも止まります。

あなたのテーマに合わせて

ライトでもダークでも、システムではなくエディタの設定に合わせます。

ワンクリックで準備完了

パッケージが足りないときも、フレームワークの新しい版が出たときも、ボタンひとつでインストールや更新ができます。

コピー＆ペースト

範囲をコピーして、行を貼り付け。ワークスペースの中でも、VS Code の中でも使えます。

コマンドパレット

リストに戻らなくても、⌘⇧P からどのワークスペースでも開けます。

ファイルもフォルダも手元に

Finder で表示、フォルダを開く、サーバーログを見る。すべてひとつのメニューから。

すべてあなたの PC の中に

アカウントは不要です。PC 上だけで動き、アクセスできるのはあなただけです。

2 つの使い方

Antigravity App 向け

プラグインとして動きます。ワークスペースは専用のタブで、エージェントとの会話のすぐ横に開きます。

インストールガイド

agy コマンドひとつでインストールできます。

VS Code 向け

VS Code、Cursor、Antigravity IDE 向けの拡張機能です。ワークスペースはそれぞれエディタのタブで開きます。

VS Code MarketplaceOpen VSX

Open VSX は Cursor と Antigravity IDE の拡張機能マーケットプレイスです。

はじめる

拡張機能は VS Code Marketplace で公開しています。Cursor と Antigravity IDE では Open VSX からインストールできます。Antigravity App では agy コマンドひとつでプラグインを入れられます。
