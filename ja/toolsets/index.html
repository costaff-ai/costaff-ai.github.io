オープンソース

エージェントのための生産性ツール

ドキュメント、スライド、表計算、ダッシュボード。エージェントが書けて、人が読めるファイルです。どれも Skills と MCP サーバーを備えたオープンソースのフレームワークです。

アプリではなくファイル

すべてはフォルダの中のテキスト。あなたの変更もエージェントの変更も、Git がすべて記録します。

ライブプレビュー

開発サーバーが、書かれたそばから実寸で表示します。

エージェントが使いこなせるツール

Skills と MCP サーバーが、作り方・確かめ方・直し方をエージェントに教えます。

自社ツール

Workspace で開けます

open-doc

React で書いたレポートを、目次・ページ番号付きの本物の A4 ページと PDF に。

open-dashboard

ほしいダッシュボードを説明するだけ。エージェントがあなたのデータベースに接続して、ライブで組み立てます。

open-spreadsheet

Excel のような表計算。独自の数式エンジン、グリッドエディタ、xlsx、MCP サーバーを備えています。

open-design-frame

コンポーネントで書くデザインフレーム。実寸で描画し、MCP エンドポイントを備えています。

ほかのツール

open-form

対話形式のステップ、回答の保存、分析まで備えたフォームとアンケート。

open-map

投影法、レイヤー、書き出しまで対応した、インタラクティブな地図とストーリーツアー。

open-recording

ブラウザで録音し、ローカルで文字起こし。どちらもエージェントに任せられます。
