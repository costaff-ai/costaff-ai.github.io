open-recording

エージェントのための録音スタジオ

ブラウザで録音し、whisper.cpp でローカルに文字起こし。どちらも MCP 経由でエージェントに任せられます。音声をどこにも送らずに、会議や講演を文字起こししたい方に。

npx -p @open-recording/core open-recording init my-recordings
GitHub で見る

できること

ブラウザで録音

スタジオのタブがマイクを担当し、エージェントが録音の開始と停止を行えます。

ローカルで文字起こし

whisper.cpp があなたの PC 上で文字起こしするので、音声が外に出ることはありません。

エージェント向け MCP ツール

開始、停止、文字起こし、文字起こしの検索、音声の横へのメモ書きまで。

ブラウザのタブを録画

タブの映像と音声を 1 本の録画にまとめ、文字起こしと字幕も付けます。

ディスク上のただのフォルダ

録音はそれぞれ、音声、文字起こし、メモが入ったフォルダです。データベースはありません。

字幕と Markdown

音声、SRT、VTT、タイムスタンプ付きの Markdown 文字起こしをダウンロードできます。

はじめる

ワークスペースを作成

コマンドひとつで作業用のフォルダができます。

npx -p @open-recording/core open-recording init my-recordings

起動する

ブラウザでライブプレビューが開きます。

cd my-recordings && pnpm add -D @open-recording/core @open-recording/mcp && pnpm exec open-recording dev --mcp

エージェントに頼む

ほしいものを伝えるだけ。エージェントがファイルを書き、画面がその場で変わっていきます。

この会議を録音して、終わったら横に要約とアクションアイテムを書いて
