お知らせ

CoStaff は 2026年11月30日 にアーカイブされます

2026年11月 公開

CoStaff のこれまでの利用状況と今後の方向性をふまえ、私たちは CoStaff Workspace とオープンソースの生産性ツールに注力することにしました。マネージャー、専門エージェント、チャットチャネル、業務アプリを含む CoStaff Agent プラットフォームは、2026年11月30日 にアーカイブされます。

変わること

  • GitHub 上の関連リポジトリは読み取り専用になります。
  • 今後、アップデートや修正は行いません。
  • Issue や Pull Request への返信は行いません。

変わらないこと

  • コードと履歴は引き続き公開し、各リポジトリのライセンスのもとで閲覧、フォーク、利用できます。
  • 本サイトの CoStaff のページは参考として残します。
  • 本サイトは引き続き運営します。

CoStaff を使ってくださった方、フィードバックをくださった方、貢献してくださった皆さまに感謝いたします。AI スタッフを作る中で学んだことが、CoStaff Workspace の土台になっています。
