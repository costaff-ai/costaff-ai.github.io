open-design-frame

Design frames, written as components

Each frame is a fixed-size artboard, such as a desktop screen, a phone screen or a poster, that your agent writes in TSX. The canvas draws it at true size and the inspector edits it by rewriting the file. For designers and developers who want the design and the code in one place.

npx @open-design-frame/core init my-frames
View on GitHub

What it does.

Frames at true size

Each frame carries its own size, and the canvas scales the view, never the contents.

Canvas edits write source

Click any element, adjust it in the inspector, and Save rewrites the TSX.

Play it like a site

Click through frames in a simulated browser or phone, following the links each frame declares.

Themes with a DESIGN.md

Tokens become CSS variables, beside a DESIGN.md that tells an agent the rules tokens cannot hold.

One zip export

Self-contained HTML, PNG at 1x, 2x and 3x, and SVG, each frame drawn at its own size.

MCP server

open-design-frame dev --mcp exposes 32 tools, and stale writes are refused.

Get started.

Create a workspace

One command makes a new folder for your work.

npx @open-design-frame/core init my-frames

Start it

The live preview opens in your browser.

cd my-frames && pnpm install && pnpm dev

Ask your agent

Say what you need. The agent writes the files and you watch them change.

Design a mobile onboarding screen and a desktop pricing page

Open it in CoStaff Workspace.

See every edit beside the conversation, in the Antigravity App or VS Code.
