open-doc

让 Agent 来写的文档

为编程 Agent 打造的文档框架：你描述想要的报告，Agent 写 React，open-doc 负责页面尺寸、目录、页码、打印排版和导出。适合需要一份经得起打印的 PDF 的人。

npx @open-document/cli init my-docs
在 GitHub 上查看

能做什么

真实的页面尺寸

页面按真正的 A4、JIS B4 或 A3 尺寸渲染，PDF 与屏幕上看到的一致。

懂规矩的自动分页

flow() 在真实 DOM 中测量内容：标题不会落在页尾，表格整体移动。

排版检查

open-doc check 会列出被裁切的内容、孤立的标题和缺失的图片，并附上源码行号。

直接在页面上编辑

检查模式把改写的文字直接写回源码，或给 Agent 留一条备注。

表格来自数据文件

导入 .csv 或 .tsv 文件，即可生成带编号和标题的表格，文件一改，表格随之更新。

Skills 和 MCP server

每个工作区都自带写作用的 Skills，open-doc dev --mcp 提供 26 个工具。

快速开始

创建工作区

一条命令新建一个文件夹。

npx @open-document/cli init my-docs

启动

在浏览器中打开实时预览。

cd my-docs && pnpm dev

交给 Agent

说出你的需求，Agent 来写文件，你看着页面随之变化。

把 notes.md 整理成一份第三季度基础设施复盘报告，要有封面和目录

在 CoStaff Workspace 中打开

Agent 的每一次修改，都实时显示在对话旁边。支持 Antigravity App 和 VS Code。
