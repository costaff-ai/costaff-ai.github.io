open-form

让 Agent 来写的表单和问卷

为编程 Agent 打造的表单框架：描述你想要的问卷、报名表或测验，Agent 写 TSX，open-form 负责布局、条件逻辑、校验和回复存储。适合不想依赖在线表单服务来收集回复的人。

git clone https://github.com/simonliu-ai-product/open-form.git && cd open-form && pnpm install
在 GitHub 上查看

能做什么

三种呈现方式

同一份 TSX 可以渲染成单页表单、分步向导，或一次一题的对话卡片。

15 种题型

文本、数字、日期、选择、排序、评分、量表、矩阵、文件上传和签名。

条件跳题与测验评分

用 when 根据前面的回答显示题目，或通过分值和解析把表单变成测验。

回复存在本地

提交内容写入 SQLite 和 JSONL，回复标签页提供统计图表，可导出 CSV 或 JSON。

带签名的 Webhook

每条回复可通过 HTTP POST 转发，并可附加 HMAC-SHA256 签名。

编辑模式改的是源码

在浏览器里修改标题、选项或必填项，直接写回 TSX。

快速开始

创建工作区

一条命令新建一个文件夹。

git clone https://github.com/simonliu-ai-product/open-form.git && cd open-form && pnpm install

启动

在浏览器中打开实时预览。

pnpm dev

交给 Agent

说出你的需求，Agent 来写文件，你看着页面随之变化。
