CoStaff Workspace

文书工作，快速搞定

你的 AI 同事就在眼前办公。
工作区与 Agent 并排同步，每一次工具调用和修改都实时呈现。

Agent 一改，页面就变

让 Agent 加一列、画一张图、多做一页幻灯片。Agent 修改文件，你正在看的页面随之变化。无需刷新、无需导出，也不用“打开文件看看”。

所有工作区，一个列表

项目里的、你添加过的、在 CoStaff Desktop 用过的，全部汇总到一处。按最近修改排序，可按类型筛选、按名称搜索。

就像编辑器自带的功能

每个工作区一个标签页

可以和代码并排打开多个。关闭标签页，服务器就会停止。

跟随你的主题

深色或浅色，工作区跟随编辑器，而不是跟随系统。

一键就绪

缺少依赖包、框架有新版本，点一下就能安装或更新。

支持复制粘贴

复制一个区域、粘贴一整行，在工作区里也能用，在 VS Code 中同样可以。

命令面板

在 ⌘⇧P 中直接打开任意工作区，无需先回到列表。

你的文件，你的文件夹

在 Finder 中显示、打开文件夹、查看服务器日志，都在同一个菜单里。

所有数据都留在你的电脑上

无需注册账号，只在本机运行，只有你能访问。

两种使用方式

Antigravity App 版

以插件形式安装。工作区在独立的标签页中打开，就在 Agent 对话旁边。

安装说明

一条 agy 命令即可安装。

VS Code 版

以扩展形式提供，支持 VS Code、Cursor 和 Antigravity IDE。每个工作区在编辑器标签页中打开。

VS Code MarketplaceOpen VSX

Open VSX 是 Cursor 和 Antigravity IDE 使用的扩展市场。

快速开始

扩展已上架 VS Code Marketplace，Cursor 和 Antigravity IDE 可以从 Open VSX 安装。Antigravity App 版用一条 agy 命令安装。

创建工作区

一条命令新建一个文件夹。

npx @open-document/cli init my-docs

安装 CoStaff Workspace
