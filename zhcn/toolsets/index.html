开源

为 Agent 打造的效率工具

文档、演示文稿、电子表格、仪表盘，Agent 能写、人能看懂，全都是文件夹里的文件。每一个都是开源框架，自带 Skills 和 MCP server。

是文件，不是应用

所有内容都是文件夹里的文本。无论是你改的还是 Agent 改的，git 都能看到。

实时预览

开发服务器边写边渲染，按实际尺寸呈现。

Agent 懂的工具

Skills 和 MCP server 告诉 Agent 怎么做、怎么检查、怎么修正。

自研工具

可在 Workspace 中打开

open-doc

用 React 写报告，输出真正的 A4 页面，包含目录、页码和 PDF。

open-dashboard

描述你想要的仪表盘，Agent 直接连接你的数据库，实时搭建出来。

open-spreadsheet

类 Excel 电子表格：自研公式引擎、单元格编辑器、xlsx 和 MCP server。

open-design-frame

用组件写设计稿，按实际尺寸绘制，并提供 MCP 接口。

更多工具

open-form

表单、问卷、报名：对话式填写、回复存储与分析。

open-map

交互式地图与 story map，投影、图层和导出都已处理好。

open-recording

在浏览器中录制、在本地转写文字，两者都交给 Agent 操作。

外部／第三方工具

open-slide 作者 1weiho

为 Agent 打造的演示文稿框架：用 React 组件做幻灯片。

可在 Workspace 中打开

open-sheet 作者 lianghsun

用 React 写电子表格模型，导出会自动重算的 .xlsx。
