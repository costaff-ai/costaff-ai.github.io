open-map

让 Agent 来画的地图与故事地图

为编程 Agent 打造的地图框架：Agent 把每张地图写成 React 组件，open-map 负责投影、图层、故事导览章节和导出。适合用地点和路线讲故事的人。

git clone https://github.com/simonliu-ai-product/open-map.git && cd open-map && pnpm install
在 GitHub 上查看

能做什么

图层就是组件

分级设色、路线、弧线、点位和热力图层，加上标记和标注，都用普通的 TSX 编写。

三种投影

Web 墨卡托、等距圆柱和正射地球仪，附带比例尺、指北针和鹰眼图。

导入 GeoJSON 和 CSV

空间数据文件可直接作为模块导入，open-map import 也能从文件生成新地图。

故事模式

用 StoryChapter 把地图变成导览，镜头平滑飞行，支持键盘切换。

查看与评论

点击任一要素查看其源码行号、留下备注，或把当前视角保存回源码。

MCP server

open-map dev --mcp 提供列出、读取、写入、检查和导入地图的工具。

快速开始

创建工作区

一条命令新建一个文件夹。

git clone https://github.com/simonliu-ai-product/open-map.git && cd open-map && pnpm install

启动

在浏览器中打开实时预览。

pnpm dev:demo

交给 Agent

说出你的需求，Agent 来写文件，你看着页面随之变化。

画一张台湾高压电网地图，每个区域一个故事章节
