open-recording

给 Agent 用的录音工作室

在浏览器中录音，用 whisper.cpp 在本地转写，让 Agent 通过 MCP 自己完成这两件事。适合想把会议或演讲转成文字稿、又不想把音频发送出去的人。

npx -p @open-recording/core open-recording init my-recordings
在 GitHub 上查看

能做什么

在浏览器中录音

工作室标签页负责麦克风，Agent 可以自己开始和停止录音。

本地转写

whisper.cpp 在你的电脑上转写，音频不会离开这台设备。

给 Agent 的 MCP 工具

开始、停止、转写、搜索文字稿，并在音频旁边写笔记。

录制浏览器标签页

把一个标签页的画面和声音录成一段，同样能转写、生成字幕。

磁盘上的普通文件夹

每段录音是一个文件夹，里面是音频、文字稿和笔记，不需要数据库。

字幕与 Markdown

下载音频、SRT、VTT，或带时间戳的 Markdown 文字稿。

快速开始

创建工作区

一条命令新建一个文件夹。

npx -p @open-recording/core open-recording init my-recordings

启动

在浏览器中打开实时预览。

cd my-recordings && pnpm add -D @open-recording/core @open-recording/mcp && pnpm exec open-recording dev --mcp

交给 Agent

说出你的需求，Agent 来写文件，你看着页面随之变化。

帮我录下这场会议，结束后在旁边写一份摘要和待办事项
