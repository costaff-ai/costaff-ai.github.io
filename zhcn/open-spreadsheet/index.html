open-spreadsheet

人和 Agent 共用的电子表格

用起来像 Excel 的电子表格，每个工作簿都是一个 JSON 文件，存的是人输入的内容：人在单元格里编辑，Agent 直接改文件。适合想把数据放进 git 的团队。

npx open-spreadsheet init my-sheets
在 GitHub 上查看

能做什么

自研公式引擎

337 个函数，遵循 Excel 的计算规则，底层不依赖任何电子表格库。

像 Excel 一样的表格界面

编辑栏、数字格式、合并单元格、冻结窗格、筛选、批注和工作表标签。

一个工作簿一个 JSON 文件

单元格存的是输入的内容（包括公式），git 能看到每一处修改。

CSV 与 Excel 导入导出

导入 .csv、.tsv 或 .xlsx，下载 .xlsx 或 CSV，全程不上传任何数据。

保护区域

锁定的单元格拒绝输入、粘贴和 MCP 写入，Agent 改不了被锁住的内容。

含 29 个工具的 MCP server

每次写入都会重新计算；如果文件在读取后被改过，写入会被拒绝。

快速开始

创建工作区

一条命令新建一个文件夹。

npx open-spreadsheet init my-sheets

启动

在浏览器中打开实时预览。

cd my-sheets && pnpm install && pnpm dev

交给 Agent

说出你的需求，Agent 来写文件，你看着页面随之变化。
