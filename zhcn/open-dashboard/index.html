open-dashboard

让 Agent 来搭的仪表盘

为编程 Agent 打造的仪表盘框架：Agent 写 SQL 和面板，open-dashboard 以只读方式在你自己的数据库上执行每条查询并绘制图表。适合希望把仪表盘当作可评审的文件、而不是 BI 工具的团队。

npx @open-dashboard/cli init my-dashboards
在 GitHub 上查看

能做什么

从设计上就是只读

浏览器只能按名称调用查询，从不发送 SQL；每种数据库引擎都以只读方式执行。

一个仪表盘两个文件

queries.sql 定义数据，index.tsx 布局面板，看 diff 就知道改了什么。

41 种内置面板

手写的 SVG 图表，从指标卡、折线图到桑基图和地图。

数据库、API 和文件

Postgres、MySQL、BigQuery、Snowflake、SQLite 等，还能接入 HTTP API、MCP server 以及 CSV、JSON 文件。

完成前先检查

open-dashboard check 会执行每条查询，并校验面板用到的每个字段和参数。

查看面板、留下备注

查看面板的 SQL、行数和耗时，留一条备注，Agent 会据此继续修改。

快速开始

创建工作区

一条命令新建一个文件夹。

npx @open-dashboard/cli init my-dashboards

启动

在浏览器中打开实时预览。

cd my-dashboards && pnpm install && pnpm dev

交给 Agent

说出你的需求，Agent 来写文件，你看着页面随之变化。

从我们的 Postgres 加上各套餐每周注册数，以及最活跃的 20 个账号

在 CoStaff Workspace 中打开

Agent 的每一次修改，都实时显示在对话旁边。支持 Antigravity App 和 VS Code。
