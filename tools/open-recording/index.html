The recording studio built for agents.

A browser-first recorder. The tab holds the microphone, the server holds the session. whisper.cpp transcribes on your machine. Nothing is uploaded.

$ npx open-recording dev --mcp

The studio — every recording is a card carrying the opening words of its transcript

01 · Why

The mic is in the tab. The state is on the server.

Only a real tab can reach a microphone. So recording happens in the browser, while the session, the files and the transcript stay on the dev server. That is what lets a person and an agent drive the same recorder.

01 · LOCAL

Nothing is uploaded.

whisper.cpp runs on your CPU. The audio, transcript and notes are files in your own folder.

02 · SHARED

One recorder. Two drivers.

A person and an agent share one session. Whoever presses stop, the other sees it immediately.

03 · FILES

A recording is a directory.

Audio, timed segments, a Markdown transcript, notes. No database, no index.

$ ls recordings/<id>/
audio.webm transcript.md
meta.json notes.md
04 · SCRIPT

Traditional Chinese on request.

Whisper always writes Simplified. Set the script and OpenCC converts it phrase by phrase — 软件 becomes 軟體 — timestamps intact.

02 · For agents

Press record over MCP. Six tools, one endpoint.

Point the agent at localhost:5274/mcp. Start the recording, stop it with transcribe: true, read the transcript back, park the summary beside the audio.

start_recordingPress record. Returns once the browser confirms the mic is open.
stop_recordingStop and finalize. Pass transcribe: true to run whisper too.
read_transcriptTimestamped Markdown, plain text, or timed segments.
search_transcriptsSearch across every transcript, with millisecond offsets.
write_notesPark a summary or action items beside the audio.
recorder_statusIs anything recording, and is a studio connected to record through.

It refuses instead of lying. start_recording waits for MediaRecorder to confirm. Tab closed or mic blocked, the agent gets a refusal that says which — not a "done".

A finished meeting — and the summary the agent wrote into notes.md

03 · Get started

Record your next meeting. One command. Arm the mic once.

Recording works with nothing else installed. Transcription needs whisper.cpp and ffmpeg; doctor prints the fix for whatever is missing.

# studio at :5274, MCP endpoint at /mcp
$ npx open-recording dev --mcp

# optional — local transcription
$ brew install whisper-cpp ffmpeg
$ npx open-recording doctor
✓ ffmpeg    ✓ whisper    ✓ model    ✓ script
