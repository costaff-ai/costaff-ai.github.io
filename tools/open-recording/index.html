open-recording

Record in the browser.
Transcribe on your machine.

open-recording gives an agent a real record button: it presses start, a studio page in your browser takes the microphone, and when it presses stop the audio lands on your disk and is transcribed by whisper.cpp. No audio ever leaves the machine.

01  Why

A meeting is the one artefact
an agent could never reach.

Node cannot open a microphone, and a transcription API means sending the room's conversation to somebody else's server. open-recording solves both: the browser holds the microphone, the dev server holds the state, and whisper.cpp does the transcription locally.

Nothing leaves the machine

whisper.cpp runs on your own CPU. The audio, the transcript and the notes are files in a folder you own — there is no upload step to opt out of.

One recorder, two drivers

A person and an agent share the same session. Whoever presses stop, the other one sees it — there is only ever one state machine.

Recordings are directories

Each one holds its audio, timed segments, Markdown transcript and notes. No database, no index — the filesystem is the truth.

Traditional Chinese, if you ask

Whisper writes Simplified whatever was spoken. Set the script and the transcript is converted phrase-aware, so a meeting in Taipei reads the way the room writes.

02  For agents

Press record over MCP.

Point your agent at http://localhost:5274/mcp. A typical run: start the recording, let the meeting happen, stop it with transcribe: true, read the transcript back, and park the summary in the notes beside the audio.

start_recordingPress record. Returns only once the browser confirms the microphone is live.
stop_recordingStop and finalize; pass transcribe: true to run whisper right away.
read_transcriptTimestamped Markdown, plain text, or timed segments.
search_transcriptsSubstring search across every transcript, with millisecond offsets.
write_notesPark a summary or action items beside the audio.
recorder_statusIs anything recording, and is a studio connected to record through.

A finished recording — and the summary the agent parked in notes.md beside the audio.

It will not lie about recording. start_recording waits for the studio page to acknowledge that MediaRecorder is actually running. If the tab is closed or the microphone is blocked, the agent gets a refusal that says which — never a success for a recording nobody is making.

03  Get started

Two commands, then arm the microphone once.

Recording works with nothing else installed. Only transcription needs whisper.cpp and ffmpeg — and doctor prints the fix for whatever is missing.

# studio at :5274, MCP endpoint at /mcp
npx open-recording dev --mcp

# optional — local transcription
brew install whisper-cpp ffmpeg
npx open-recording doctor
