CoStaff Workspace

Get the paperwork done, fast.

Your AI coworker, at work right in front of you.
The workspace sits beside the agent, and every tool call and edit shows up as it happens.

Live as the agent works.

Ask for a new column, a chart, another slide. The agent edits the files, and the page you are looking at changes with them. No refresh, no export, no “open the file to check”.

Every workspace, one list.

Workspaces in your project, the ones you added, the ones you used in CoStaff Desktop. Sorted by what changed last, filtered by kind, found by name.

At home in your editor.

A tab per workspace

Open several side by side with your code. Close a tab and its server stops.

Your theme

Light or dark, the workspace follows the editor, not the system.

Ready in a click

Missing packages, or a newer framework: one button installs or updates it.

Copy and paste

Copy a range, paste a row. It works inside the workspace, even in VS Code.

Command palette

Open any workspace from ⌘⇧P without going to the list.

Your files, your folders

Reveal in Finder, open the folder, read the server log, from one menu.

Everything stays on your computer.

No account. It runs only on your computer, and only you can reach it.

Two ways to use it.

For the Antigravity App

A plugin with its own tab, beside the agent’s conversation.

Install guide

For VS Code

An extension for VS Code, Cursor and the Antigravity IDE. Each workspace opens in an editor tab, between your files and the agent.

VS Code MarketplaceOpen VSX

Get started.

The extension is on the VS Code Marketplace, and on Open VSX for Cursor and the Antigravity IDE. For the Antigravity App, install the plugin with one agy command.
