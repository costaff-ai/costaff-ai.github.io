open-form

Forms and surveys your agent writes

A form framework for coding agents: describe the survey, registration or quiz, your agent writes the TSX, and open-form handles layout, logic, validation and response storage. For anyone collecting answers without a hosted form service.

git clone https://github.com/simonliu-ai-product/open-form.git && cd open-form && pnpm install
View on GitHub

What it does.

Three ways to present

One TSX file renders as a single page, a step-by-step wizard or one question at a time.

15 field types

Text, number, date, choices, ranking, rating, scale, matrix, file upload and signature.

Conditional logic and quizzes

Show fields based on earlier answers with when, or grade a form with points and explanations.

Responses stored locally

Submissions go to SQLite and JSONL, with charts and CSV or JSON export in the Responses tab.

Signed webhooks

Forward each submission over HTTP POST with an optional HMAC-SHA256 signature.

Edit mode writes source

Change labels, options or required flags in the browser and they are saved into the TSX.

Get started.

Create a workspace

One command makes a new folder for your work.

git clone https://github.com/simonliu-ai-product/open-form.git && cd open-form && pnpm install

Start it

The live preview opens in your browser.

pnpm dev

Ask your agent

Say what you need. The agent writes the files and you watch them change.
