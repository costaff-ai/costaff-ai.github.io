open-dashboard

Dashboards your agent builds

A dashboard framework for coding agents: your agent writes the SQL and the panels, and open-dashboard runs every query read-only against your own database and renders the charts. For teams who want dashboards as reviewable files instead of a BI tool.

npx @open-dashboard/cli init my-dashboards
View on GitHub

What it does.

Read-only by design

The browser names a query and never sends SQL; every engine runs it read-only.

Two files per dashboard

queries.sql defines the numbers and index.tsx lays out the panels, so a diff shows what changed.

41 built-in panels

Hand-written SVG charts, from stat tiles and line charts to Sankey diagrams and maps.

Databases, APIs and files

Postgres, MySQL, BigQuery, Snowflake, SQLite and more, plus HTTP APIs, MCP servers and CSV or JSON files.

A check before done

open-dashboard check runs every query and verifies each column and parameter a panel names.

Inspect and leave notes

See a panel's SQL, rows and timing, and leave a note your agent turns into the next edit.

Get started.

Create a workspace

One command makes a new folder for your work.

npx @open-dashboard/cli init my-dashboards

Start it

The live preview opens in your browser.

cd my-dashboards && pnpm install && pnpm dev

Ask your agent

Say what you need. The agent writes the files and you watch them change.

Add weekly signups by plan and the 20 most active accounts from our Postgres
