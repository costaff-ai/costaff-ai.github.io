Open source

Productivity tools, built for agents.

Documents, decks, sheets, dashboards: files an agent can write and a person can read. Each one is an open-source framework with skills and an MCP server.

Files, not apps

Everything is text in a folder. Git sees every change, from you or the agent.

Live preview

A dev server renders the work as it is written, at its real size.

Tools the agent knows

Skills and MCP servers tell the agent how to build, check and fix its work.

Our tools.

Opens in Workspace

open-doc

Reports written as React, rendered as real A4 pages with an outline, page numbers and a PDF.

open-dashboard

Describe the dashboard you want. Your agent builds it, live, over your own database.

open-spreadsheet

An Excel-like spreadsheet with its own formula engine, grid editor, xlsx and an MCP server.

open-design-frame

Design frames written as components, drawn at true size, with an MCP endpoint.

More tools

open-form

Forms and surveys with conversational steps, a response store and analytics.

open-map

Interactive maps and story tours, with projections, layers and export handled.

open-recording

Record in the browser, transcribe locally, and let an agent drive both.
